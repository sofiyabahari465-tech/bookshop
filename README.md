# 📚 کتاب‌لند | فروشگاه آنلاین کتاب

یه سایت فروشگاهی کتاب خفن و مدرن ساخته شده با **HTML + CSS + JavaScript** خالص — بدون هیچ فریم‌ورکی! 🚀

## ✨ ویژگی‌ها

- 🎨 **طراحی مدرن و خفن** با تم تاریک/روشن
- 📱 **کاملاً ریسپانسیو** — روی موبایل، تبلت و دسکتاپ عالی کار می‌کنه
- 🛒 **سبد خرید کامل** با ذخیره در localStorage
- 🔍 **جستجو و فیلتر** پیشرفته بر اساس دسته‌بندی و قیمت
- 📊 **مرتب‌سازی** بر اساس قیمت و محبوبیت
- 🎯 **۱۶ کتاب نمونه** در ۸ دسته‌بندی مختلف
- ⚡ **انیمیشن‌های نرم** و افکت‌های جذاب
- 🌙 **تم دارک/لایت** قابل تغییر
- 🔥 **RTL** و فارسی کامل

## 📂 ساختار پروژه

```
bookstore/
├── index.html          # صفحه اصلی
├── css/
│   └── style.css       # تمام استایل‌ها
├── js/
│   ├── data.js         # دیتای کتاب‌ها و توابع کمکی
│   └── script.js       # منطق اصلی برنامه
├── .gitignore
└── README.md
```

## 🚀 اجرا

کافیه فایل `index.html` رو در مرورگر باز کنی. همین! نیازی به سرور یا نصب چیزی نیست.

```bash
# یا با live-server برای توسعه
npx live-server
```

## 🛠️ تکنولوژی‌ها

- **HTML5** — ساختار سمنتیک
- **CSS3** — Flexbox, Grid, Custom Properties, Animations
- **JavaScript (Vanilla)** — بدون فریم‌ورک، ES6+
- **Vazirmatn Font** — فونت فارسی زیبا
- **localStorage API** — ذخیره سبد خرید
